# KNTX [LAB] — Engineered for Concrete

> High-Density Urban Techwear & Industrial Apparel E-Commerce Experience.  
> Official Release: DROP 004.

---

## ⚡ Architecture & Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite 8](https://vite.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + Custom Brutalist Industrial Design System
- **Kinetic Engine**: [GSAP](https://greensock.com/gsap/) + [Lenis Smooth Scroll](https://lenis.darkroom.engineering/)
- **Typography**: Syne (Black & Extra Bold), JetBrains Mono, Plus Jakarta Sans
- **Linting & Code Quality**: [Oxlint](https://oxc.rs/)
- **Hosting & Edge Delivery**: [Vercel](https://vercel.com/) (configured in `vercel.json` with security headers & SPA fallback)

---

## 🛠️ Features

- **Kinetic Hero Ignition**: Staggered neon voltage entrance with parallax physics.
- **Interactive Shutter Airlock**: Scroll-driven poly-carbonate mechanical decompression effect.
- **Tactical 2.6X Optical Loupe**: Real-time cursor coordinates and macro texture inspection.
- **Anthropometric Size Calculator**: Biometric recommendation engine calibrated for drop-shoulder garments and articulated cargo pants.
- **Direct WhatsApp Checkout**: Sanitized and formatted purchase order manifest generation.
- **Enterprise Technical SEO & Security**: Complete Open Graph, Schema.org JSON-LD graph (`WebSite`, `Organization`, `ClothingStore`, `ItemList`), `robots.txt`, and `sitemap.xml`.
- **GDPR & Privacy Center**: Integrated preferences modal and storage controls.

## 🚀 Development & Build

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run Oxlint
npm run lint

# Production build
npm run build

# Preview build locally
npm run preview
```

---

## 🌐 Deployment

Configured for zero-config deployment on Vercel:
1. Push to GitHub (`main` branch).
2. Import project in Vercel.
3. Build command: `npm run build`, output directory: `dist`.
